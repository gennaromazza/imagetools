Invio e ricezione locale o remota

Scambia file. Senza complicazioni.

FileX Send trasferisce file in entrambe le direzioni tramite QR o link temporaneo. Il cliente usa soltanto il telefono, senza installare applicazioni e senza creare un account.

Due modalità

In studio o a distanza.

Wi-Fi e QR locale

Ricevi direttamente sulla rete dello studio quando computer e cliente sono vicini.

Link remoto

Condividi un collegamento temporaneo utilizzabile anche quando il PC non è acceso.

Recupero automatico

I file in attesa vengono consegnati al computer quando torna disponibile.

Protezione dei dati

Temporaneo per progettazione.

I file remoti restano in attesa soltanto per completare la consegna e vengono eliminati automaticamente un’ora dopo la consegna verificata.
