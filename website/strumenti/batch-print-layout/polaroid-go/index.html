In pochi passaggi

Dalle foto alle stampe.

1. Carica le foto

Trascina i file o apri una cartella.

2. Scegli Polaroid Go

Per tutte le foto o solo per quelle che vuoi.

3. Sistema l'inquadratura

Sposta, ingrandisci o ruota solo gli scatti che lo richiedono.

4. Esporta

Ogni foto diventa un file pronto da stampare, con la sua cornice.

Le misure seguono la guida ufficiale Polaroid. Polaroid e Polaroid Go appartengono ai rispettivi titolari. FileX non è collegata a Polaroid.
