Il problema quotidiano di uno studio fotografico

Una persona entra in negozio e vuole stampare alcune foto conservate sul telefono. Inviare tutto tramite WhatsApp può ridurre la qualità o creare confusione; la posta elettronica è scomoda con molti allegati; collegare ogni telefono al PC fa perdere tempo; chiedere al cliente di registrarsi a un servizio cloud complica un'operazione che dovrebbe durare pochi minuti.

FileX Send nasce esattamente da questa situazione. Il fotografo prepara una sessione, il cliente scansiona un QR e dal browser sceglie le fotografie. I file arrivano nella cartella stabilita sul computer dello studio, pronti per essere controllati e stampati.

La differenza pratica: non devi spiegare un software al cliente. Gli mostri il QR, lui sceglie i file e preme “Invia ora”.

Cosa può fare FileX Send

  • Ricevere dal cliente: foto, video, documenti, altri file e, quando supportato dal browser, intere cartelle.
  • Inviare al cliente: scegli file o cartelle dal PC e condividili con QR o link.
  • Lavorare in locale: trasferimento diretto sulla rete dello studio, senza passare dal cloud.
  • Lavorare a distanza: crea un collegamento Internet temporaneo che rimane utilizzabile anche se chiudi l'app o spegni il PC.
  • Non richiedere account al cliente: per chi invia o scarica è sufficiente il browser.
  • Gestire più sessioni: ogni cliente ha nome, cartella, data, quantità e storico dei file.
  • Evitare sovrascritture: se arrivano file con lo stesso nome, il programma crea un nome progressivo invece di sostituire quello precedente.
  • Recuperare sessioni remote: una sessione Internet ancora attiva può essere ripristinata nell'app.

Modalità locale: il cliente è qui con te

La modalità locale è pensata per il banco dello studio, un photo booth o qualsiasi situazione in cui cliente e computer si trovano nello stesso luogo.

  1. Apri FileX Send e scegli Ricevi file.
  2. Seleziona Qui con me.
  3. Inserisci un nome riconoscibile per il cliente e controlla la cartella di destinazione.
  4. Il programma rileva la rete Wi-Fi e prepara due QR: il primo collega il telefono alla rete, il secondo apre FileX Send nel browser.
  5. Il cliente sceglie le fotografie dalla galleria oppure apre documenti e altri file.
  6. Dopo l'invio, sul PC vedi nomi, quantità e dimensioni e puoi aprire direttamente la cartella ricevuta.

I file rimangono nella rete locale e vengono trasferiti direttamente al computer. Internet non è necessario, ma telefono e PC devono poter comunicare sulla stessa rete Wi-Fi.

Modalità remota: il cliente è a casa o altrove

Se il cliente non è più in negozio, scegli A distanza. FileX Send genera un QR e un link temporaneo da copiare e inviare tramite il canale che preferisci. Il cliente apre la pagina dal browser e carica i file senza creare un account.

La scadenza del collegamento è configurabile tra 15 minuti e 7 giorni; se non scegli un termine diverso, la durata iniziale è di 24 ore. Il link continua a funzionare anche quando FileX Send è chiuso e il computer è spento. Alla riapertura, il programma recupera la sessione e scarica nella cartella locale i file in attesa.

Questa modalità usa temporaneamente il servizio cloud FileX. I file già scaricati dal computer vengono programmati per la cancellazione remota dopo un'ora. Il collegamento non è un archivio permanente e non sostituisce il backup dello studio.

Inviare file dal PC al cliente

FileX Send non serve soltanto a ricevere. Dalla schermata iniziale scegli Invia file, indica se il cliente è vicino oppure a distanza e aggiungi file o cartelle dal PC. Puoi usare il pulsante di selezione oppure trascinare gli elementi nell'area di condivisione; le sottocartelle vengono incluse automaticamente.

Il cliente apre il QR o il link e trova l'elenco dei file preparati. Può scaricarli singolarmente o usare “Scarica tutti”. In modalità remota la disponibilità termina alla scadenza impostata.

Un flusso reale per le foto da stampare

  1. Il cliente entra con le foto sul telefono.
  2. Crei una sessione locale con il suo nome.
  3. Il cliente scansiona i QR e seleziona le immagini originali dalla galleria.
  4. Apri la cartella ricevuta e controlli formato, orientamento e risoluzione.
  5. Se devi stampare più fotografie sullo stesso foglio, prosegui con Batch Print Layout.
  6. Quando hai concluso, termini la sessione del cliente.

Lo stesso sistema può essere usato durante eventi, per raccogliere contenuti dagli ospiti, oppure per consegnare file finiti senza chiedere al destinatario di installare FileX.

FileX Send, LocalSend o Dropbox?

Sono strumenti simili soltanto in parte. La scelta corretta dipende dal problema che devi risolvere.

LocalSend

Gratuito e open source

Ideale per: trasferire file tra propri dispositivi vicini.

Funziona sulla rete Wi-Fi locale, senza cloud e senza Internet. È multipiattaforma, ma normalmente va aperto sui dispositivi coinvolti.

Sito ufficiale LocalSend

Dropbox File Requests

Basic gratuito: 2 GB di spazio

Ideale per: raccogliere file dentro un archivio Dropbox.

Chi invia non deve avere un account. I file occupano lo spazio Dropbox del fotografo; con Basic, Plus e Family ogni caricamento richiesto può arrivare fino a 2 GB, mentre alcuni piani professionali arrivano a 250 GB.

Richieste file Dropbox

FileX Send

Incluso in FileX: 12 €/mese o 100 €/anno

Ideale per: il rapporto diretto tra studio fotografico e cliente.

Unisce trasferimento locale e remoto, invio e ricezione, QR, link temporanei, cartelle organizzate per cliente e nessun account per il destinatario.

Quando scegliere ciascuna soluzione

  • Scegli LocalSend se vuoi un trasferimento gratuito, offline e occasionale tra dispositivi che controlli e che sono sulla stessa rete.
  • Scegli Dropbox File Requests se usi già Dropbox come archivio cloud e vuoi che i caricamenti finiscano direttamente nel tuo spazio.
  • Scegli FileX Send se vuoi un flusso semplice per clienti non tecnici, sia al banco sia a distanza, integrato con gli altri strumenti fotografici FileX.

Controlli prima di iniziare

  • Assegna alla sessione il nome del cliente o del lavoro.
  • Verifica la cartella di destinazione prima di mostrare il QR.
  • Per il trasferimento locale, controlla che telefono e PC possano comunicare sulla stessa rete.
  • Per l'invio remoto, imposta una scadenza proporzionata al tempo concesso al cliente.
  • Non usare un link temporaneo come unica copia dei file importanti.

Domande frequenti

Il cliente deve installare FileX Send?

No. Apre il QR o il link nel browser e usa la normale selezione dei file del telefono o del computer.

Posso ricevere documenti oltre a foto e video?

Sì. La pagina separa la galleria da “altri file” e permette anche di scegliere cartelle quando il browser lo supporta.

Posso inviare io dei file al cliente?

Sì. FileX Send è bidirezionale: puoi ricevere dal cliente oppure preparare file e cartelle che il cliente scaricherà dal QR o dal link.

Il trasferimento locale passa dal cloud?

No. In modalità locale i file restano nella rete del negozio e arrivano direttamente al PC.

Quanto rimangono disponibili i file remoti?

Il link può durare da 15 minuti a 7 giorni. Dopo che FileX Send ha scaricato un file ricevuto, la copia remota viene programmata per la cancellazione entro un'ora.
