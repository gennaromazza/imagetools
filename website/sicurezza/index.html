FileX / Sicurezza
Principi di prodotto

I file del fotografo restano del fotografo.

FileX privilegia l’elaborazione locale e limita il cloud alle funzioni che ne hanno effettivamente bisogno.

Elaborazione locale

Selezione, archivio, conversione, ricerca, composizione, stampa e manutenzione lavorano sulla postazione dell’utente.

Cloud circoscritto

FileX Send usa il servizio remoto soltanto quando viene scelta la consegna tramite link.

Cancellazione automatica

I file remoti vengono eliminati un’ora dopo la consegna verificata al computer destinatario.

FileX Send locale

Nella modalità Wi-Fi/QR i file vengono trasferiti al computer attraverso la rete disponibile. Il cliente utilizza una pagina mobile senza installare un’applicazione e senza creare un account.

FileX Send remoto

Il link remoto consente l’upload anche quando il computer non è acceso. I file rimangono temporaneamente nello storage europeo in attesa del recupero e sono cancellati automaticamente dopo la consegna verificata.

Aggiornamenti

Suite e tool dispongono di feed separati. Ogni componente propone la propria versione e viene aggiornato senza ricostruire inutilmente gli altri strumenti.

Responsabilità dell’utente

FileX non sostituisce una strategia di backup. Prima di operazioni di eliminazione, conversione o manutenzione è necessario conservare copie indipendenti dei lavori importanti e verificare sempre origine e destinazione.

Segnalazioni

Per problemi di sicurezza non pubblicare file personali o dati sensibili in una issue pubblica. Scrivi a image.studio.fotografico@gmail.com descrivendo il problema senza allegare materiale dei clienti.
